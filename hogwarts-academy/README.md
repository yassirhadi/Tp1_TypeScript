# Hogwarts Academy — TypeScript Mini Project

TP TypeScript : generics, utility types, conditional types, index signatures,
type guards et method decorators (legacy).

## Lancer le projet
```bash
npm install
npm start          # exécute src/main.ts
npm run typecheck  # vérifie les types
```
